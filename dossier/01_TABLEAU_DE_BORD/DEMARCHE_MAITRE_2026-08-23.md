# Démarche maître — FINCA MARIA

Date de cadrage : 23/08/2026

## But

Arrêter de traiter les pièces comme une succession de documents isolés et travailler désormais par **questions de gestion** : que sait-on, qu'est-ce qui est prouvé, qu'est-ce qui manque, et quelle décision cela permet de prendre.

## État du corpus

### Entré dans le système

- 25 PDF uniques, 473 pages, OCRisés et classés ; les doublons exacts sont exclus.
- Documents Word / PowerPoint familiaux pris en compte comme sources de contexte ou synthèses, avec niveau de preuve distinct.
- Les principales familles de pièces sont reliées : cadastre, terres, production, coopérative, banque, maison, énergie, travaux, décisions familiales.

### Important

**Entré dans le système ne signifie pas totalement exploité.**

Trois niveaux doivent rester distincts :

1. `RECU_ET_CLASSE` — document identifié et rangé.
2. `EXPLOITE` — informations utiles extraites et croisées.
3. `VERROUILLE` — points importants confirmés par pièce primaire / contrôle visuel / rapprochement suffisant.

## Méthode de travail à partir de maintenant

### CHANTIER A — Terres & production

Objectif : savoir ce que la Finca produit réellement et comment cela évolue.

À suivre par campagne :

- kilos d'olives ;
- kilos d'huile ;
- rendement Finca ;
- rendement de référence Málaga / zone locale lorsque disponible ;
- mode d'exploitation : bail 15 %, transition, gestion directe ;
- dépenses agricoles ;
- événements agronomiques / météo / traitements ;
- niveau de preuve.

Priorités :

- verrouiller campagne 2025/26 ;
- faire confirmer par San Juan la complétude des campagnes anciennes ;
- traiter séparément les campagnes sous bail 15 % et les campagnes en gestion directe ;
- ne jamais mélanger aides PAC, ventes / liquidations coopérative et production physique.

### CHANTIER B — Dépenses agricoles & prestataires

Objectif : savoir combien coûte réellement l'exploitation et pour quoi.

Pour chaque dépense :

`date → prestataire/fournisseur → travail/produit → parcelle si connue → montant → paiement → campagne → preuve`.

Priorités :

- San Juan / Vitines / produits / traitements 2024-2026 ;
- rapprocher factures et paiements ;
- distinguer matériel, produits, main-d'œuvre, récolte, taille, traitements ;
- conserver `NON_ETABLI` lorsqu'un retrait d'espèces ne peut pas être affecté.

### CHANTIER C — Maison

Objectif : disposer d'un historique fiable des charges, travaux et obligations.

Sous-blocs :

- électricité : largement verrouillée 2013-2016 ;
- gaz / butane : historique identifié, continuité à compléter ;
- IBI / cadastre : série documentée, décision cadastrale finale encore à obtenir ;
- travaux : facturas, paiements, doublons et avoirs ;
- travaux actuels : à tracer à partir de maintenant comme journal opérationnel.

Priorités :

- finir `facturas 2.pdf` pages 1-9 ;
- retrouver les pièces cadastrales finales ;
- démarrer un suivi 2026 des travaux à faire / faits / coût / photo avant-après.

### CHANTIER D — Banque / compte commun

Objectif : comprendre les flux utiles à la Finca sans attribuer abusivement les opérations.

Règles fixes :

- compte mixte ≠ compte exclusivement Finca ;
- co-titulaire ≠ auteur d'une opération ;
- retrait espèces ≠ destination prouvée ;
- une facture et un débit ne sont rapprochés que si les éléments concordent.

Priorités :

- anciennes lignes San Juan / aides à contrôler visuellement ;
- remises de chèques / pagarés encore non qualifiées ;
- produire uniquement des synthèses redacted dans l'interface familiale.

### CHANTIER E — Famille & gouvernance

Objectif : séparer l'historique familial de la règle actuelle.

Déjà établi :

- règlements 2010/2015 = historiques / documents de travail ;
- comptes rendus de réunions = preuve de discussion/décision, pas forcément d'exécution ;
- baux = pièces primaires lorsqu'ils sont retrouvés.

Priorités :

- écrire un règlement actuel ;
- organisation des présences ;
- clés / accès ;
- qui décide quoi ;
- qui paie quoi ;
- procédure simple pour travaux et dépenses.

## Ordre de travail recommandé

### Étape 1 — Fermer les analyses documentaires déjà ouvertes

Ne pas ouvrir de nouveau grand chantier documentaire avant de fermer :

- `facturas 2.pdf` pages 1-9 ;
- contrôles agricoles / bancaires encore ambigus réellement utiles ;
- classement final des documents San Juan / baux retrouvés.

### Étape 2 — Construire la vision exploitation

Créer un tableau campagne par campagne réunissant : production, rendement, référence locale, coût agricole documenté, modèle d'exploitation et anomalies à expliquer.

### Étape 3 — Construire le suivi opérationnel 2026-2027

À partir de maintenant, ne plus attendre des années avant de reconstruire : chaque facture, traitement, récolte, travaux maison ou décision entre directement dans le journal courant.

### Étape 4 — Chercher seulement les pièces externes à forte valeur

Priorité :

1. historique officiel complet San Juan ;
2. décision cadastrale définitive / bases IBI ;
3. décisions ASAJA / Junta ;
4. pièces de prestataires agricoles ;
5. pièces de caisse uniquement lorsqu'elles peuvent résoudre un point important.

### Étape 5 — Transformer les données en outils simples

Le logiciel doit montrer en priorité :

- `Aujourd'hui / À faire` ;
- `Campagne en cours` ;
- `Production & rendement` ;
- `Dépenses` ;
- `Travaux maison` ;
- `Présences / réservations` ;
- `Questions à régler` ;
- `Baúl des preuves` en arrière-plan.

Le Baúl sert à prouver. Le tableau de bord sert à agir.

## Discipline de preuve

Pour toute donnée importante, conserver l'un de ces statuts :

- `CONFIRME` — preuve primaire suffisamment nette ;
- `CALCULE` — résultat mathématique à partir de données confirmées ;
- `PROBABLE` — concordance forte mais incomplète ;
- `A_VERIFIER` — OCR, scan faible ou portée incertaine ;
- `NON_ETABLI` — ne pas conclure.

## Principe directeur

La prochaine phase n'est plus : **« lire tous les documents »**.

Elle devient : **« piloter la Finca avec les documents déjà structurés, et ne revenir aux pièces que lorsqu'une question précise l'exige »**.
