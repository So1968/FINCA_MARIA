# Finca Maria

Projet familial lié aux terres héritées en Andalousie.

## Statut du dossier

**Matière brute / en structuration**

Le projet est encore en phase de clarification : beaucoup de pièces existent, mais elles doivent être reliées, vérifiées et transformées en dossier compréhensible pour les héritiers.

## Transformation attendue

> terres héritées, documents dispersés et suspicion de mauvais entretien  
> → dossier clair, preuves reliées, campagnes agricoles lisibles et décisions familiales structurées.

## Problème réel

La famille a hérité d'une exploitation comprenant notamment des oliviers en Andalousie.

Le problème identifié est une baisse importante de production, avec plusieurs zones floues :

- ancien contrat avec une logique 15 % / 85 % ;
- passage ensuite en prestations de services ;
- baisse forte des kilos produits ;
- factures peu détaillées ;
- traitements phytosanitaires difficiles à relier aux achats ;
- documents coopérative à récupérer ;
- risque de doublons dans les calculs ;
- besoin de distinguer faits prouvés, éléments déclarés et estimations.

## Fonction centrale du projet

Permettre aux héritiers de comprendre, campagne par campagne :

1. ce qui a été produit ;
2. ce qui a été facturé ;
3. ce qui a été payé ;
4. ce qui a été réellement fait sur les terres ;
5. ce qui est prouvé ;
6. ce qui reste flou ;
7. quelles questions doivent être posées à la coopérative et à l'agriculteur.

## Règle centrale

> On ne compte pas un document.  
> On compte une réalité prouvée.

Un ticket, une facture, un extrait de compte, une vidéo ou une note peuvent parler de la même réalité.  
Ils doivent être reliés, pas additionnés automatiquement.

## Acteurs

| Acteur | Rôle |
|---|---|
| S.C.A. Agrícola San Juan | Coopérative : kilos, liquidations, produits, alertes techniques |
| Agrícola Vitines / López Gallego José | Agriculteur / prestataire local |
| ASAJA Málaga | PAC, administratif, aides |
| Héritiers | Décisions, demandes, contrôle familial |

## Données clés à ce stade

- environ 180 oliviers ;
- environ 5,6666 hectares d'oliviers selon le tableau ;
- ancien régime : la famille percevait 15 % de la production ;
- extrapolations 100 % utilisées uniquement pour l'ancien régime ;
- passage en prestations de services autour de 2023 ;
- campagnes très faibles à partir de 22/23 ;
- besoin de comparer avec les données climatiques / sectorielles ;
- besoin de récupérer les factures détaillées coopérative ;
- besoin de demander la ventilation des factures Vitines.

## Dossier opérationnel lié

Le travail concret est suivi dans le dossier Finca Maria.

Ce dossier contient :

- notes de réunion ;
- analyses ;
- demandes à la coopérative ;
- demandes à l'agriculteur ;
- tableaux de suivi ;
- règles anti-doublons ;
- éléments préparatoires pour les héritiers.

## Ce qu'il ne faut surtout pas faire

- ne pas mélanger Finca Maria avec un autre projet familial ;
- ne pas mélanger ancien régime 15/85 et prestations de services ;
- ne pas additionner les tickets, récapitulatifs et extraits sans vérifier ;
- ne pas pousser sur GitHub les documents sensibles bruts ;
- ne pas accuser sans preuve ;
- ne pas transformer une estimation en fait officiel.

## Prochain geste

- état des documents disponibles ;
- évolution des récoltes ;
- années problématiques ;
- comparaison avec le secteur ;
- factures coopérative à demander ;
- facture Vitines 2026 à ventiler ;
- décisions familiales à prendre.
