# FINCA MARIA — recadrage stratégique

Mise à jour : 24/08/2026

## Pourquoi la stratégie change

Les échanges du 24/08/2026 et les nouvelles pièces montrent qu'il faut distinguer strictement **la source qui produit l'information** de la personne qui la reçoit ensuite.

Exemple décisif : Peláez explique que, pour la fiscalité, il reçoit les documents officiels transmis par la coopérative et se base dessus. Il n'est donc pas témoin ni source du détail des apports, repartos, liquidations ou achats intervenus entre-temps.

La règle générale devient :

**NE DEMANDER À CHAQUE ACTEUR QUE CE QU'IL PEUT PROUVER PAR SON PROPRE SYSTÈME OU SES PROPRES PIÈCES.**

# 1. Hiérarchie des sources

## A. S.C.A. Agrícola San Juan — source primaire production / coopérative

San Juan est la source à privilégier pour :

- vales / tickets d'apport ;
- dates et kilos d'olives ;
- kilos d'huile ;
- rendement ;
- repartos ;
- anticipos ;
- liquidation finale ;
- compte `Proveedor / Socio-Proveedor` ;
- compte `Cliente` ;
- achats coopérative ;
- certificats / résumés annuels émis par la coopérative ;
- historique des écritures de leur système.

Les reçus 2025/26 prouvent que plusieurs repartos peuvent reprendre **exactement les mêmes kilos**. Les kilos inscrits sur plusieurs repartos ne sont donc jamais additionnés physiquement.

Priorité documentaire : **2018/19 à 2025/26**, puis 2014/15 à 2017/18.

## B. Peláez — source fiscale en aval

Peláez est à utiliser pour :

- déclarations fiscales réellement déposées ;
- documents fiscaux qu'il a reçus ;
- certificats transmis par des tiers pour préparer les déclarations ;
- qualification fiscale des montants ;
- copie des pièces qu'il conserve ;
- période exacte pendant laquelle il a assuré la gestion fiscale ;
- identification du document ayant servi de base à une ligne fiscale particulière.

Peláez n'est pas la source primaire pour :

- kilos récoltés ;
- détail des apports ;
- repartos ;
- liquidation de campagne ;
- déroulement des travaux agricoles ;
- réalité d'une récolte céréalière ;
- décisions de San Juan.

Ne plus lui demander d'expliquer ces flux s'il ne les produit pas.

## C. ASAJA / Junta de Andalucía — source PAC

Pour la PAC, la source pertinente est le dossier administratif :

- demande déposée ;
- accusé de dépôt ;
- requerimientos ;
- alegaciones ;
- résolution ;
- droits ;
- cessions ;
- aides accordées ;
- paiements.

Priorités :

1. issue finale du double dossier 2019 ;
2. motif et pièces du refus 2022 ;
3. dossier 2024 et ce qui a changé après 2022 ;
4. rattachement exact du paiement agricole de 4 551,14 € visible fiscalement en 2025 ;
5. dossier complet et statut 2026 ;
6. historique d'une éventuelle cession des droits envisagée en 2020.

## D. Banque — source de paiement uniquement

La banque sert à prouver :

- qu'un montant est entré ou sorti ;
- à quelle date ;
- avec quel libellé bancaire.

Elle ne sert pas à reconstruire seule la nature agronomique ou juridique du flux.

`MOUVEMENT BANCAIRE ≠ CAMPAGNE ≠ FACTURE ≠ TRAVAUX`, sauf rapprochement par référence / montant / date / pièce source.

## E. Vitines / José López Gallego — source contrats / prestations / exploitation

À rechercher auprès d'eux ou dans leurs pièces :

- contrat signé postérieur au 11/03/2020 ;
- factures détaillées ;
- prestations réalisées ;
- paiements ;
- semences / labour / moisson ;
- bons de pesée / vente céréales ;
- destination des récoltes ;
- pièces permettant de comprendre la base d'exploitation après 2020.

Une explication orale reste un indice ; la priorité est la pièce.

## F. Famille / comptes rendus

Les comptes rendus servent à :

- dater les préoccupations ;
- conserver la mémoire des discussions ;
- retrouver des pistes / documents ;
- savoir ce que la famille croyait à une date donnée.

Ils ne remplacent pas les pièces San Juan, PAC, bancaires ou contractuelles.

# 2. Nouveau modèle de lecture

FINCA MARIA doit désormais séparer quatre chaînes avant tout rapprochement.

## Chaîne physique

`campagne → ticket/apport → kg olives → kg huile → rendement → total coopérative`

Source principale : San Juan.

## Chaîne financière

`reparto / avance → liquidation → retenue / compensation → paiement bancaire`

Sources : San Juan + banque.

## Chaîne fiscale / administrative

`certificat tiers → déclaration fiscale → PAC / résolution → aide → paiement`

Sources : Peláez / Agencia Tributaria pour fiscalité ; ASAJA/Junta pour PAC.

## Chaîne juridique / exploitation

`contrat → droit d'exploiter → charges → travaux → prestataire → facture → paiement`

Sources : contrats + prestataires + banque.

Ne jamais combler un trou d'une chaîne avec une autre chaîne sans pièce de raccord.

# 3. Règles nouvelles verrouillées

1. **Année fiscale ≠ campagne agricole.**
2. **Reparto ≠ nouvel apport de kilos.** Les reçus 2025/26 le prouvent directement.
3. **Revenus fiscaux San Juan ≠ valeur complète d'une campagne** sans rapprochement calendrier / campagne.
4. **Peláez ≠ source de la production.** Il est une source des déclarations et pièces fiscales qu'il reçoit.
5. **PAC ≠ fiscalité.** La PAC doit être reconstruite depuis ASAJA/Junta.
6. **Aide demandée ≠ aide accordée ≠ paiement.**
7. **Banque ≠ explication du flux.** Elle confirme le paiement après identification de la source.
8. **Achats de semences ≠ preuve de récolte ni de vente de céréales.**
9. **Pas de total Cliente + Proveedor.** Ce sont des sens économiques opposés.
10. **Pas de nouvel OCR ancien si un export officiel peut être obtenu à la source.** L'OCR ancien devient un outil de contrôle / secours.
11. **2019–2026 est désormais la priorité opérationnelle.** Les archives 2014–2018 passent en seconde phase, sauf référence nécessaire pour comprendre un mécanisme.
12. **Absence de pièce ≠ faute / détournement / absence d'opération.**
