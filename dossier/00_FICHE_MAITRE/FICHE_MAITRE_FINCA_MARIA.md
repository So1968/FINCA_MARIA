## Nature du projet

FINCA MARIA est un outil autonome de mémoire, de pilotage et de protection du bien familial situé en Andalousie.

Il est travaillé dans Azoth Studio, qui sert d’atelier de fabrication, mais il doit rester compréhensible, exportable et transmissible hors d’Azoth Studio.

Il couvre :
- les oliviers ;
- les cultures ;
- les productions ;
- les factures ;
- les prestataires ;
- les preuves ;
- la maison familiale ;
- les règles d’usage ;
- les décisions familiales ;
- les points de conflit ou d’alerte.

## Objectif principal

Sortir du flou.

Le projet doit permettre de savoir :
- ce qui a été fait ;
- quand cela a été fait ;
- par qui ;
- pour quel montant ;
- avec quelle preuve ;
- avec quel résultat ;
- ce qui reste à clarifier ;
- quelles décisions familiales ont été prises.

## Phrase centrale

Protéger le Cortijo, ce n’est pas seulement surveiller les terres : c’est organiser la mémoire, les preuves, les règles et les usages du lieu.

## Règle de méthode

Le projet doit rester factuel, daté et documenté.

On évite :
- les accusations non prouvées ;
- les souvenirs flous ;
- les mélanges de campagnes ;
- les conclusions trop rapides ;
- les décisions orales non tracées ;
- les anciens noms de travail qui peuvent faire croire que Cortijo dépend d’un autre produit.

On privilégie :
- dates ;
- preuves ;
- documents ;
- photos ;
- vidéos ;
- factures ;
- tableaux simples ;
- questions ouvertes ;
- décisions écrites.

## Phrase de protection

FINCA MARIA doit permettre de protéger le lieu sans envenimer les relations : écrire les faits, garder les preuves, clarifier les règles et préserver le bien familial.

## Règle d’autonomie

FINCA MARIA est fabriqué dans Azoth Studio, mais il doit pouvoir être transmis comme un dossier autonome à la famille, à un gestionnaire, à un expert agricole ou à un avocat.
