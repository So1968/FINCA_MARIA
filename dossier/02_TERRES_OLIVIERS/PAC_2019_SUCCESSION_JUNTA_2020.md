# PAC 2019 / succession / Junta 2020 — reconstruction prudente

## Objet

Cette fiche isole la séquence PAC 2019-2020 afin de ne plus mélanger :

- la demande PAC déposée au nom de María Serrano ;
- la Solicitud Única 2019 déposée au nom de María Josefa ;
- les échanges ASAJA / héritiers ;
- la procédure administrative Junta 2020 ;
- les interprétations familiales figurant dans les comptes rendus.

Aucun DNI/NIF complet, numéro de dossier complet, adresse privée ou référence bancaire sensible n'est reproduit ici.

## Niveaux de preuve

- `[P-ANT]` : pièce primaire identifiée et partiellement extraite dans les études antérieures ; original non rouvert dans cette passe.
- `[MAIL]` : contenu repris d'un mail ASAJA cité dans un compte rendu familial.
- `[CR]` : résumé / interprétation figurant dans un compte rendu familial.
- `[R]` : information de contexte à confirmer par une résolution ou pièce administrative finale.

## 1. Solicitud Única 2019 au nom de María Josefa

Les archives CamScanner antérieures contiennent une **Solicitud Única — Campaña 2019** au nom de **María Josefa de los Rios Serrano**.

Statut : `[P-ANT]`.

Éléments visibles dans les extractions antérieures :

- campagne : **2019** ;
- titulaire / demanderesse : **María Josefa** ;
- rubrique sollicitant les droits dont elle est titulaire pour la campagne ;
- page `Declaración Responsable (Agricultor Activo)` ;
- page relative à un **pacto de indivisión d'au moins six ans en cas de communauté héréditaire** ;
- page `RESUMEN SUPERFICIES` ;
- présence d'**AVENA** dans le résumé des cultures / surfaces ;
- page `RESUMEN DE DERECHOS`.

### Ce que cela prouve

Une demande PAC 2019 distincte a bien été montée au nom de María Josefa.

### Ce que cela ne prouve pas encore

- qu'elle a été acceptée ;
- qu'elle a été payée ;
- qu'elle a remplacé définitivement la demande au nom de María Serrano ;
- le détail exact des hectares, recintos et droits, faute de relecture finale des pages primaires.

## 2. Mail ASAJA cité au conseil de famille du 12/11/2019

Le compte rendu du **12 novembre 2019** reproduit / traduit un mail ASAJA.

Dans le passage espagnol cité, ASAJA indique que la Consejería demande :

1. la **déclaration des héritiers de María Serrano García** ;
2. la **renonciation de tous les héritiers à la demande PAC présentée au nom de María Serrano**.

Statut : `[MAIL]` — contenu d'un mail ASAJA reproduit dans un document familial.

### Point important

Le sens littéral du passage ASAJA est : **renoncer à la demande déposée au nom de María Serrano**.

## 3. Contradiction interne dans le même compte rendu familial

Plus loin, le résumé familial du même conseil de famille indique qu'il y aurait eu **deux demandes** :

- une première demande au nom de María Serrano ;
- une seconde demande au nom de María Josefa, rendue possible par des pouvoirs donnés par les héritiers.

Le résumé familial ajoute qu'ASAJA aurait demandé d'**annuler la dernière demande**, c'est-à-dire celle de María Josefa.

Statut : `[CR]`.

### Incohérence documentaire

Cette phrase du résumé familial entre en conflit avec le mail ASAJA cité juste avant, qui parle explicitement de renoncer à la demande **au nom de María Serrano**.

FINCA MARIA ne choisit donc pas arbitrairement entre les deux versions.

**Statut : CONFLIT_DE_SOURCE_A_RESoudre.**

La seule façon de fermer ce point est de retrouver :

- l'écrit de désistement effectivement signé ;
- son destinataire / enregistrement ;
- la résolution administrative qui indique quelle demande a été retirée, rejetée ou maintenue.

## 4. Contexte familial sur l'origine des deux demandes

Le compte rendu familial explique que :

- la première demande aurait été déposée dans l'urgence autour du décès de María ;
- une seconde demande aurait ensuite été préparée au nom de María Josefa ;
- les héritiers lui auraient donné pouvoir pour agir en leur nom ;
- la famille cherchait à savoir quelle demande conserver et laquelle annuler.

Statut : `[CR/R]`.

Ces éléments éclairent le contexte, mais ne remplacent pas la décision administrative.

## 5. Junta 2020 — `TRAMITE DE AUDIENCIA`

Le lot CamScanner 2020 contient une pièce de la **Consejería de Agricultura, Ganadería, Pesca y Desarrollo Sostenible — D.G. de Ayudas Directas y de Mercados — Servicio de Ayudas** portant le titre :

**`TRAMITE DE AUDIENCIA`**.

Statut : `[P-ANT] PIECE PRIMAIRE IDENTIFIEE`.

À ce stade, l'extraction disponible permet de confirmer l'existence de la procédure d'audience, mais pas encore :

- son objet exact ;
- la demande PAC concernée ;
- le motif juridique / administratif ;
- le délai de réponse ;
- la résolution finale.

Il est donc interdit d'écrire que cette audience a confirmé un rejet ou un paiement tant que la pièce n'est pas relue intégralement.
