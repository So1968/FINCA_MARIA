# PAC / SIGPAC — audit historique FINCA MARIA

Mise à jour : 23/08/2026

## Objet

Cette fiche réintègre dans FINCA MARIA les éléments PAC / SIGPAC repérés dans les anciens lots CamScanner et dans les études documentaires V32 à V46.

Elle ne remplace pas les originaux privés. Les anciens rapports de structuration et les OCR sont des couches d'indexation / d'analyse : tout fait déterminant doit être recontrôlé sur la pièce primaire avant usage juridique, fiscal ou administratif.

## Règles de preuve

- `[P-ANT]` : l'étude antérieure indique qu'une pièce primaire a établi directement le fait ; original non rouvert dans cette passe.
- `[MAIL]` : contenu d'un mail reproduit / cité dans une pièce familiale.
- `[CR]` : compte rendu / interprétation familiale.
- `[R]` : fait rapporté par un rapport de structuration / transmission antérieur ; à recontrôler sur l'original avant verrouillage final.
- `[C]` : calcul / reconstitution.
- `[D]` : information déclarée / familiale.

Aucun identifiant personnel complet, numéro de dossier sensible ou donnée bancaire n'est reproduit ici.

## 1. Contrôle PAC 2006/2007

Les études antérieures identifient un ensemble de **14 images** correspondant à un contrôle PAC assisté par photographie / image satellite, avec une visite de terrain datée autour du **12/07/2007**.

Statut : `[P-ANT] PRIMAIRE_ADMINISTRATION_AGRICOLE — A REOUVRIR POUR EXTRACTION COMPLETE`.

Points structurants rapportés :

- contrôle lié à la campagne **2006/2007** ;
- référence à une image aérienne / orthophoto ;
- certaines pages portent la mention `Sin incidencia` ;
- d'autres signalent que **l'usage observé ne coïncide pas avec l'usage déclaré** ;
- les pages concernent des parcelles / recintos et leurs usages : elles ne doivent pas être additionnées mécaniquement comme surface totale de la Finca.

### Alerte de complétude

Le lot possède 14 images alors que la pagination interne observée va jusqu'à 15 sur certaines pages. Avant toute extraction exhaustive des recintos / surfaces, il faut déterminer :

- s'il manque réellement une page ;
- si une couverture ou une page non numérotée explique l'écart ;
- si toutes les pages appartiennent bien au même contrôle.

Statut : `[P-ANT] DOSSIER DETAILLE IDENTIFIE — EXTRACTION RECINTOS EN COURS DE VERROUILLAGE`.

- parcelle **25** : recintos **1, 2, 3** visibles dans la série ;

Le dossier fait aussi apparaître des lignes de demande / résumé relatives à :

Conclusion interdite : transformer les surfaces d'une déclaration PAC en surface cadastrale définitive, ou présenter une ligne d'aide comme accordée / payée sans résolution ou preuve financière.
