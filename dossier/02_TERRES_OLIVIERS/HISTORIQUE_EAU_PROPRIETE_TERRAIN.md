# Historique eau / propriété / terrain — FINCA MARIA

Mise à jour : 23/08/2026

## Objet

Cette fiche réintègre des pièces foncières et hydrauliques anciennes retrouvées dans le corpus antérieur. Elle distingue strictement :

1. les **descriptions registrales** de fincas ;
2. les **parcelles / espaces d'usage commun** ;
3. les **ouvrages d'eau** ;
4. les **états cadastraux agricoles datés**.

Les noms complets de personnes, numéros de finca, références cadastrales complètes, identifiants fiscaux et autres données sensibles ne sont pas reproduits ici.

## Niveau de preuve

- `[P-ANT]` : pièce primaire identifiée et extraite dans le corpus antérieur ; original non rouvert dans cette passe.
- `[P-STRUCT]` : existence et qualification d'un groupe documentaire établies par la structuration du corpus.
- `[R]` : note / correspondance historique à rapprocher de la pièce registrale.
- `[C]` : calcul effectué à partir de valeurs documentées.

## 1. Grande finca rurale — description registrale historique

Une note registrale ancienne décrit une finca rustique provenant du Cortijo de los Alemanes avec :

- superficie : **11,3933 ha** ;
- olivar : **6,9767 ha** ;
- monte alto : **0,3130 ha** ;
- reste en **cereal de secano** ;
- présence dans les limites d'un **chemin commun** aux propriétaires issus du Cortijo et de l'**Arroyo del Rodado**.

Statut : `[P-ANT] DESCRIPTION_REGISTRALE_HISTORIQUE`.

Cette description ne reçoit pas une date agricole automatique. Elle ne doit donc pas être fusionnée avec la Cámara Agraria 1999, le cadastre 2002 ou le cadastre 2017 comme s'il s'agissait d'une seule mesure.

## 2. Parcelle d'eau de 400 m²

Une autre description registrale identifie une **parcelle rustique distincte de 400 m²**, soit environ 20 m × 20 m, dans laquelle se trouvent :

- **deux nacimientos de agua** ;
- un **depósito distribuidor** ;
- **onze llaves de corte** ;
- **onze tuberías**.

Statut : `[P-ANT] INFRASTRUCTURE_HYDRAULIQUE_REGISTRALE`.

La présence de onze vannes et onze conduites indique un système de distribution partagé ou subdivisé, mais la pièce extraite ici ne suffit pas à attribuer aujourd'hui une vanne ou une conduite à chaque titulaire.

### Prudence sur la propriété

Une autre description de finca voisine / associée mentionne en limite une **parcelle de 400 m² contenant le dépôt d'eau**, attribuée dans cette description historique aux héritiers d'un membre de la famille, et indique également la présence d'une **source** dans la finca décrite.

Ces deux passages sont compatibles avec l'existence d'un ouvrage hydraulique familial historique, mais FINCA MARIA ne doit pas conclure que la grande finca agricole, la parcelle de 400 m² et les parcelles 25/27 forment juridiquement une seule unité sans identification des numéros de finca registrale.

## 3. Parcelle d'usage commun de 1 536 m²

Une description registrale distincte porte sur une parcelle rustique :

- superficie : **1 536 m²** ;
- destination indiquée : **usage commun exclusif de tous les propriétaires des maisons et eras provenant du Cortijo de Alemanes** ;
- présence d'une **alberca** à l'intérieur de cette parcelle.

Statut : `[P-ANT] ESPACE_COMMUN_REGISTRAL`.

C'est un élément important : le corpus documente historiquement au moins un espace foncier explicitement qualifié d'**usage commun**, et cet espace comporte un ouvrage d'eau.

### Ce que cela ne prouve pas encore

- le régime juridique actuel de cet espace ;
- la liste actuelle des ayants droit ;
- les quotes-parts actuelles ;
- les droits d'accès, d'entretien ou de prélèvement d'eau aujourd'hui ;
- la relation exacte entre cette alberca et le dépôt distributeur de la parcelle de 400 m².

## 6. Comparaison 2002 ↔ 2017

Le dossier cadastral déjà intégré donne pour 2017 :

| Usage | 2002 | 2017 | Écart documentaire |
|---|---:|---:|---:|
| Olivier | **5,5229 ha** | **5,6666 ha** | **+0,1437 ha** |
| Labourable | **4,9293 ha** | **5,6901 ha** | **+0,7608 ha** |
| Pâture | non isolée dans l'état 2002 | **0,1384 ha** | non comparable directement |
| Total parcelles 25+27 | **10,4522 ha** | **11,4951 ha** | **+1,0429 ha** |

L'écart total entre ces deux états documentaires est d'environ **+9,98 %**, tandis que la surface oléicole n'augmente que d'environ **+2,60 %**.

### Interprétation autorisée

Les descriptions administratives des surfaces ont changé entre les états documentaires. La variation est surtout portée par les terres non oléicoles.

### Interprétations interdites sans pièce complémentaire

Ne pas conclure automatiquement à :

- un achat d'environ 1,04 ha ;
- une erreur du cadastre ;
- une extension physique de l'exploitation ;
- un changement de propriété ;
- une conversion exacte de cultures.

Il peut exister des différences de définition, de sous-parcelles, de mesure, de révision cadastrale ou de rattachement administratif.

## 7. Autres repères de surface à garder séparés

FINCA MARIA possède désormais plusieurs photographies historiques qui ne sont pas identiques :

- description registrale historique : **11,3933 ha**, dont **6,9767 ha d'olivier** ;
- Cámara Agraria 1999 : **11,39 ha**, dont **6,39 ha d'olivar** et environ **5 ha de veza** ;
- cadastre 2002 parcelles 25+27 : **10,4522 ha**, dont **5,5229 ha d'olivier** ;
- cadastre 2017 parcelles 25+27 : **11,4951 ha**, dont **5,6666 ha d'olivier**.

Ces chiffres ne sont pas des versions concurrentes d'une même mesure : ils viennent de **documents, dates et systèmes administratifs différents**.

## Règle FINCA MARIA

**EAU / PROPRIÉTÉ / USAGE COMMUN sont liés, mais ne sont pas synonymes.**

Un ouvrage présent sur une parcelle ne prouve pas à lui seul qui détient aujourd'hui le droit d'usage, la propriété de l'eau ou l'obligation d'entretien.
