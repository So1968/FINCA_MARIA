# Règlement familial d’usage de la maison du Cortijo — V1

## 1. Principe général

La maison du Cortijo est un bien familial commun. Son usage doit être respectueux, organisé et traçable.

## 2. Personnes autorisées

À définir :
- membres de la famille ;
- conjoints ;
- enfants ;
- invités ;
- personnes extérieures éventuelles ;
- conditions d’accord préalable.

## 3. Réservation / occupation

À définir :
- comment demander une période ;
- qui valide ;
- comment éviter les chevauchements ;
- durée maximale éventuelle ;
- priorités éventuelles.

## 4. Clés et accès

À définir :
- qui possède les clés ;
- qui peut les transmettre ;
- interdiction ou non de faire des doubles ;
- accès à la maison ;
- accès aux dépendances ;
- accès aux terres et au matériel.

## 5. Entretien

À définir :
- ménage avant départ ;
- linge ;
- poubelles ;
- rangement ;
- état des lieux simple ;
- signalement des dégradations.

## 6. Frais

À définir :
- participation aux charges ;
- eau ;
- électricité ;
- gaz ;
- petites réparations ;
- travaux ;
- achats partagés.

## 7. Travaux

À définir :
- ce qui peut être fait librement ;
- ce qui nécessite un accord familial ;
- qui valide ;
- comment conserver les devis, factures et décisions.

## 8. Invités, animaux, fêtes

À définir :
- invités autorisés ou non ;
- animaux autorisés ou non ;
- fêtes / repas ;
- respect du voisinage ;
- sécurité.

## 9. Dégradations

À définir :
- comment signaler ;
- qui répare ;
- qui paie ;
- comment garder une trace.

## 10. Désaccords

À définir :
- discussion familiale ;
- trace écrite ;
- décision datée ;
- médiation si besoin.

## Règle de base

Personne ne doit pouvoir imposer un usage flou de la maison au reste de la famille.
