Ce fichier est la porte d’entrée unique du projet Finca Maria.

Il sert à retrouver rapidement :

- les documents de continuité ;
- les campagnes agricoles ;
- les productions connues ;
- les preuves ;
- les factures ;
- les questions ouvertes ;
- les décisions ;
- les prochaines actions techniques.

## 1. Nature du projet

FINCA MARIA est un outil / dossier autonome construit à partir d’un patrimoine agricole familial réel situé en Andalousie.

Azoth Studio est l’atelier de fabrication de Sofia. Finca Maria peut y être travaillé, mais il doit rester exportable et compréhensible hors d’Azoth Studio.

L’outil Finca Maria doit transformer des informations dispersées en mémoire de travail exploitable : documents, tickets, factures, vidéos, messages, dates, questions et décisions.

Objectif : suivre l’exploitation par la chronologie, les preuves et les rapprochements.

## 3. Campagnes agricoles suivies

### Campagne 2023-2024

Éléments connus :

- CPNA 23/24 : 2 294 kg d’olives ;
- rendement : 16,96 % ;
- huile indiquée : 389,06 kg.

Statut : donnée historique à intégrer dans l’outil.

### Campagne 2024-2025

Éléments connus :

- CPNA 24/25 : 6 551 kg d’olives ;
- rendement : 20,72 % ;
- huile indiquée : 1 357,37 kg.

Attention : les documents CPNA 24/25 datés en 2025 relèvent de la campagne 2024-2025.

### Campagne 2025-2026

Éléments connus :

- au moins un ticket / apport partiel visible autour de 6 541 kg ;
- environ deux apports d’environ 6 000 kg chacun sont à consolider ;
- total provisoire à vérifier : environ 12 000 kg et quelques ;
- une ligne de suivi mentionne 7 943 kg au 23/03/2026 / reçu 6139.

Attention : ne pas traiter un ticket partiel comme total définitif.

Statut : campagne à consolider avec les tickets, le récapitulatif coopérative et les pièces justificatives.

## 4. Repère historique de production

## 13. Règle de rapprochement

Chaque élément important doit pouvoir être relié à au moins une des catégories suivantes :

- campagne ;
- date ;
- personne / prestataire ;
- document ;
- facture ;
- paiement ;
- preuve ;
- question ;
- point de vigilance ;
- décision.

Quand un élément ne peut pas être relié, il doit apparaître comme zone floue ou point à clarifier.
