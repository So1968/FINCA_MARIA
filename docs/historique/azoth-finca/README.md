# Azoth Finca — ancien nom de travail

## Statut actuel

Ce dossier est conservé comme **archive de nommage**.

Le nom officiel actuel de l’outil est :

```text
FINCA MARIA
```

Azoth Finca a été un nom de travail utilisé pendant la structuration du projet, mais il ne doit plus être employé comme nom principal.

## Clarification

- **Azoth Studio** : atelier de fabrication / outil interne de Sofia.
- **FINCA MARIA** : outil autonome exportable, construit à partir du dossier familial réel.
- **Pack Finca Maria** : version transmissible à la famille, à un gestionnaire, à un expert agricole ou à un avocat.
- **Azoth Finca** : ancien nom de travail, conservé seulement pour comprendre l’historique.

## Documents actifs

Les documents actifs doivent être repris ou consolidés dans :

```text
docs/cortijo-alemanes/
02_PRODUITS/FINCA_MARIA/
10_PACKS/POUR_SOEUR/PACK_FINCA_MARIA/
```

## Règle de reprise

Ne pas recréer un produit nommé Azoth Finca.

Ne pas présenter Finca Maria comme un simple cas d’usage d’un autre outil.

Ne pas supprimer brutalement ce dossier avant d’avoir vérifié que son contenu utile a été repris dans Finca Maria.
