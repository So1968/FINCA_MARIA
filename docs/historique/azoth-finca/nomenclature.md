# Nomenclature corrigée — FINCA MARIA

## Nom officiel actuel

Le nom officiel de l’outil / produit est :

```text
FINCA MARIA
```

## Statut d’Azoth Finca

Azoth Finca est un **ancien nom de travail**.

Il peut rester mentionné uniquement pour comprendre l’historique du projet, mais il ne doit plus être utilisé comme nom principal de l’outil.

## Rôles à distinguer

### Azoth Studio

Azoth Studio est l’atelier de fabrication / l’outil interne de Sofia.

Il sert à concevoir, développer, documenter et préparer les produits.

### FINCA MARIA

FINCA MARIA est le produit autonome exportable.

Il sert à suivre le dossier familial réel : campagnes agricoles, productions, coopérative, PAC, travaux, factures, preuves, réunions, décisions, maison, anomalies et exports.

### Pack Finca Maria

Le Pack Finca Maria est la version transmissible.

Il doit pouvoir être donné à la famille, à un gestionnaire, à un expert agricole ou à un avocat sans obliger le lecteur à comprendre toute l’architecture Azoth Studio.

## Règle simple

Dire : **FINCA MARIA**.

Ne pas dire : **Azoth Finca** comme nom actuel du produit.

## Règle de dossiers

Les dossiers actifs sont :

```text
02_PRODUITS/FINCA_MARIA/
docs/cortijo-alemanes/
10_PACKS/POUR_SOEUR/PACK_FINCA_MARIA/
```

Le dossier suivant est conservé comme archive de nommage :

```text
docs/azoth-finca/
```

Aucune suppression ne doit être faite sans vérification préalable.

## Formulations à utiliser

- FINCA MARIA — tableau de bord
- FINCA MARIA — campagnes agricoles
- FINCA MARIA — journal d’exploitation
- FINCA MARIA — BAÚL des preuves
- FINCA MARIA — CASA
- FINCA MARIA — registre des questions
- FINCA MARIA — registre des anomalies
- FINCA MARIA — pack transmissible

## Formulations à éviter

- Azoth Finca comme nom actuel de l’outil ;
- Cortijo comme simple module dépendant d’Azoth ;
- mélange Cortijo / Finca sans préciser l’historique ;
- comparaison ou emprunt de vocabulaire à d’autres produits.

## Phrase de cap

```text
Azoth Studio est l’atelier.
FINCA MARIA est le produit autonome.
Le pack Cortijo est la version transmissible.
```
