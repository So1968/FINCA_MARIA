# Azoth Finca — ancien nom de travail

## Statut actuel

**Azoth Finca n’est plus le nom principal de l’outil.**

Le nom officiel actuel du projet / outil est :

```text
FINCA MARIA
```

Ce fichier est conservé comme trace historique, parce que le projet a été travaillé un temps sous le nom Azoth Finca.

## Clarification définitive

- **Azoth Studio** : atelier de fabrication / outil interne de Sofia.
- **FINCA MARIA** : produit autonome exportable, travaillé dans Azoth Studio mais transmissible hors d’Azoth Studio.
- **Azoth Finca** : ancien nom de travail à ne plus utiliser comme nom principal.

## Règle de reprise

Ne pas créer de nouveau produit nommé Azoth Finca.

Ne pas présenter Finca Maria comme un simple cas d’usage d’un autre produit.

La bonne formulation est :

```text
FINCA MARIA est un outil autonome fabriqué dans Azoth Studio, mais destiné à pouvoir vivre hors d’Azoth Studio.
```

## Que faire de ce dossier ?

Ce dossier peut rester présent temporairement pour conserver l’historique.

Mais les contenus actifs doivent être repris ou stabilisés dans les dossiers Cortijo :

```text
docs/cortijo-alemanes/
02_PRODUITS/FINCA_MARIA/
10_PACKS/POUR_SOEUR/PACK_FINCA_MARIA/
```

## À ne pas faire

- Ne pas supprimer brutalement ce dossier sans vérifier son contenu.
- Ne pas utiliser Azoth Finca comme nom actuel de l’outil.
- Ne pas mélanger les documents actifs Cortijo avec des anciens brouillons de nommage.
- Ne pas créer deux outils concurrents pour le même projet.

## Phrase de cap

```text
Azoth Studio est l’atelier.
FINCA MARIA est le produit autonome.
Le pack Cortijo est la version transmissible.
```
