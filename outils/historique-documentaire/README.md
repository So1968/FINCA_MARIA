# Anciennes analyses documentaires

Ces scripts conservent les étapes de traitement du corpus (versions 2 à 46).
Ils ne font pas partie du démarrage, du build ni du serveur de FINCA MARIA.

Leurs chemins historiques peuvent viser l’ancien poste ou AZOTH_STUDIO. Ne pas les exécuter
directement sur le BAÚL réel : relire les entrées, les sorties et les chemins, puis travailler sur une copie.
Les traitements utiles à reprendre devront être adaptés et testés individuellement dans ce dépôt.
