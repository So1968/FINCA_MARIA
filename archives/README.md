# Versions antérieures conservées

Ces fichiers ne sont ni construits ni déployés par les commandes actuelles.

- `ancienne-api/` : ancien service, remplacé par `server/` pour le déploiement courant.
- `ancienne-demo/` : ancienne présentation familiale, remplacée par `app/family/`.
- `pack-famille/` : fichiers uniques de l’ancien pack ; les doublons exacts du dossier principal ne sont pas recopiés.

Le manifeste de migration indique la source de chaque fichier et les rapprochements de doublons.
