# Variante GPS conservée

Ces fichiers uniques proviennent du commit `f27d196a54016d1dbb4ff9a8635d4e786c71ee5e` d’AZOTH_STUDIO, variante d’intégration GPS signalée sur le PC et retrouvée dans l’historique GitHub.

Ils sont conservés dans FINCA_MARIA pour préparer une reprise ultérieure du module terrain. Ils ne font pas partie du build ni du déploiement actuel. L’application principale utilise la version complète auditée et testée issue de `4318312`.

Avant toute activation, adapter le raccordement au point d’entrée autonome, contrôler les autorisations et la politique de géolocalisation du déploiement, puis tester les positions, le stockage et l’export sur téléphone. Les configurations Vercel ici sont historiques.

Le manifeste donne les empreintes d’origine. Les fichiers du poste de Sofia et son commit local ne sont pas modifiés par cette copie.
