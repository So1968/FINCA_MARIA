# VERSION — PACK FINCA MARIA

## Version actuelle du pack

```text
PACK_FINCA_MARIA — V0.2 — Socle transmissible utilisable
```

Date de version : 17/07/2026

## Rôle du pack

Ce pack est la version transmissible de FINCA MARIA.

Il doit permettre à une autre personne d’ouvrir le projet, comprendre sa logique, déposer des documents, valider leur classement, suivre les points ouverts et préparer une transmission sans connaître Azoth Studio.

## Parcours attendu

```text
Ouvrir Cortijo
→ choisir Accueil, BAÚL, Suivi ou Export
→ déposer les documents
→ vérifier le tri proposé
→ valider le classement
→ traiter les questions et anomalies
→ exporter un état du dossier
```

## Contenu fonctionnel V0.2
