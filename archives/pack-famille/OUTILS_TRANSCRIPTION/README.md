# Transcription intégrée — Finca Maria

Ce module permet de transcrire gratuitement des fichiers audio ou vidéo avec Whisper local.

## Usage

Installer Whisper :

    ./installer-whisper-local.sh

Transcrire un fichier choisi dans Téléchargements :

    ./transcrire-choisir-fichier.sh

Transcrire un fichier précis :

    ./transcrire-audio.sh "/chemin/vers/fichier.mp4"

## Important

Les audios, vidéos et transcriptions sensibles doivent rester en local.

Ne pas les envoyer sur GitHub.
