# Pack Finca Maria

Ce pack est la version autonome du projet Finca Maria.

Il sert à organiser :
- les terres et oliviers ;
- les campagnes de production ;
- les factures et prestataires ;
- le Baúl des preuves ;
- la maison et son règlement ;
- le calendrier d'occupation ;
- les décisions familiales ;
- les questions à clarifier ;
- les exports famille / avocat.

Azoth Studio est l'atelier de fabrication.
Le Pack Finca Maria est prévu pour pouvoir vivre hors d'Azoth Studio.

Les preuves privées, vidéos, audios, factures et documents sensibles ne doivent pas être envoyés sur GitHub.
