# Baúl des preuves — Finca Maria

Le Baúl est le coffre des preuves du projet Cortijo.

## Compartiments

- 00_A_CLASSER : sas d'arrivée.
- 01_FACTURES : factures, devis, paiements.
- 02_COOPERATIVE : documents liés à la coopérative.
- 03_PHOTOS_VIDEOS : photos et vidéos utiles.
- 04_MAISON : éléments concernant la maison.
- 05_TERRES_OLIVIERS : terres, oliviers, cultures.
- 99_ARCHIVES : anciens éléments conservés.

Les fichiers originaux sensibles restent en local.

Ne pas envoyer sur GitHub :
- vidéos privées ;
- photos privées ;
- factures ;
- documents juridiques ;
- transcriptions sensibles.
